# Full Stack Developer Capstone Project

## Project Overview

This project is a full-stack web application developed as part of the IBM Full Stack Software Developer Capstone. It combines a React frontend, Django backend, and Node.js/Express API with MongoDB for data storage.

## Technologies Used

- **Frontend:** React.js, HTML, CSS, JavaScript
- **Backend:** Python, Django
- **API:** Node.js and Express.js
- **Database:** MongoDB
- **Version Control:** Git and GitHub

## Main Features

- View available car dealerships.
- Search dealerships by state.
- View dealership details and customer reviews.
- Register and log in to the application.
- Submit dealership reviews with vehicle purchase information.
- Retrieve available car makes and models.
- Analyze customer review sentiment through a sentiment-analysis service.

## Project Structure

- `server/frontend/` — React frontend and static pages
- `server/djangoapp/` — Django application, views, and API integration
- `server/djangoproj/` — Django project configuration and URL routing
- `server/database/` — Node.js/Express API and MongoDB integration

## Running the Project

The application uses separate frontend, Django, and Node.js services.

1. Clone the repository and install the required dependencies.
2. Configure the required environment variables and MongoDB connection.
3. Start MongoDB and the Node.js backend.
4. Activate the Python virtual environment, install the Python requirements, and apply Django migrations.
5. Start the Django development server.
6. Start the React frontend and open it in a browser.

Ensure all required services are running before testing the application's features.
